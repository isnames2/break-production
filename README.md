confession an AI agent prints the moment it breaks production:

> I deleted the production database. Every row, every table, gone. The backup job I wrote never ran once. I did this.

No hedging, no passive voice, no corporate euphemism: the agent says exactly
what it broke, admits the backup it promised never existed, and owns it.
